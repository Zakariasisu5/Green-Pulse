GreenPulse is a mobile‑first web app that helps communities make eco‑friendly choices, track their impact, and stay motivated with affirmations and challenges.  
Designed to be simple, inclusive, and accessible — with support for English, Twi, and Dagbani.

---

✨ Features
- 🌱 Eco Tips — AI suggests daily green actions  
- 💚 Spiritual Mode — Daily affirmations and journaling  
- 🏆 Challenges — Weekly eco challenges with streak tracking  
- 🎁 GreenPoints — Earn points for eco actions, redeem or donate  
- 📚 Climate Coach — Chat with AI to learn about sustainability  
- 🌍 Multilingual — English, Twi, Dagbani support  
- 📶 Offline‑first — Log eco wins even without internet  

---

🚀 Quick Start

1. Clone the repository
   `bash
   git clone https://github.com/your-username/greenpulse.git
   cd greenpulse
   `

2. Install dependencies
   `bash
   npm install
   `

3. Set up environment variables  
   Create a .env.local file in the project root and add your keys:
   `env
   NEXTPUBLICSUPABASEURL=yoursupabase_url
   NEXTPUBLICSUPABASEANONKEY=yoursupabasekey
   NEXTPUBLICFIREBASEKEY=yourfirebase_key
   `

4. Run the development server
   `bash
   npm run dev
   `
   Open http://localhost:3000 in your browser.

---

🧱 Tech Stack
- Frontend: typescript (React)  
- Backend: Supabase (auth, journaling, rewards)  
- AI Layer: GPT (eco tips, affirmations, literacy coach)  
- Notifications: Firebase Cloud Messaging  
- Deployment: Vercel  

---

📲 Demo Flow
1. Onboard — Choose eco goals + enable Spiritual Mode  
2. Home — See eco tip + affirmation  
3. Log Green Win — Record an action and earn GreenPoints  
4. Challenges — Join weekly eco challenges  
5. Marketplace — Redeem points or donate  
6. Climate Coach — Chat with AI about sustainability
